# 🧮 (Calculator)

![Screenshot of the calculator](./preview.jpg)

## 📖 About the Project

This is a simple browser-based **calculator** project developed using **HTML**, **CSS**, and **JavaScript**.

It aims to provide an easy-to-use interface for performing basic arithmetic operations (addition, subtraction, multiplication, and division) with a modern and responsive design that adapts to all screen sizes.

## ✨ Features

- Perform basic arithmetic operations: `+`, `-`, `×`, `÷`.

- Clear button to filter the field.

- Backspace button to delete the last digit.

- Instantly displays results when the equals key (=) is pressed.

- Responsive design that works on phones, tablets, and computers.

- Colors and animation effects (Hover/Click) to enhance the user experience.

- Switch between three modes [Night, Day, Eco]

- Button to display who is the programmer and who is the designer

## 🛠️ Technologies Used

- **HTML5** – Page structure.

- **CSS3** – Formatting, design, and responsiveness.

- **JavaScript (ES6)** – Programming logic for calculations and interaction.

## 💻 How to Run Locally (On Your Device)

1. Download the project as a ZIP file or use the command:

```bash
  git clone https://github.com/Fadi-Yaj/Calculator
```

2. Open the downloaded folder.
3. Double-click the index.html file to open it directly in the browser.
4. Start by using the calculator!

## 🖱️ How to use

- Press the numbers (`0`-`9`) to form the number
- Choose the arithmetic operation (`+`, `-`, `×`, `÷`)
- Press the (`=`) button to get the result
- Use the (`Reset`) button to clear everything, or (`Del`) to clear only the last number
